# 공개용 업무보고 샘플

기존 회의 참석 보고와 현장조사 결과 보고의 구성을 일반화해 만든 예시입니다. 실제 내부 보고서 원문이 아니며 이름·연락처·실제 기관 정보는 포함하지 않습니다. 보고자 칸은 비어 있습니다. 법령 판단이나 실제 조사 결과를 입증하는 자료가 아닙니다.

- `01_회의참석보고.hwpx`: 회의개요, 회의결과, 조치계획
- `02_현장조사결과보고.hwpx`: 조사개요, 조사결과, 조치계획
- 같은 이름의 `.txt`: GitHub에서 읽을 수 있는 본문
- 같은 이름의 `.svg`: kordoc으로 렌더링한 양식 미리보기

앱의 승인 양식과 기존 `report_loop.py` 엔진으로 생성하고 기호·글꼴·공백 검증 및 렌더링을 확인했습니다. 실제 한글 출력은 PC의 글꼴 환경에 따라 차이가 날 수 있습니다.

## 참고사례로 사용하기

1. HWPX 파일 화면에서 **Download raw file**을 눌러 두 문서를 같은 폴더에 저장합니다.
2. 앱에서 **참조 폴더·코퍼스** → 폴더 추가 → **코퍼스 구축·갱신**을 실행합니다.
3. 새 보고서의 실제 사실을 대화창에 입력하고 기존 보고서의 구성과 문체를 참고하도록 요청합니다.

TXT와 HWPX는 같은 본문이므로 참고 폴더에는 HWPX만 넣으면 됩니다. SVG는 열람용입니다. 새 업무의 날짜·장소·조사결과는 별도로 입력해야 하며 샘플의 사실을 그대로 재사용하면 안 됩니다.

[설치 및 전체 사용 안내로 돌아가기](../README.md)

두 샘플의 보고목적은 **결과보고(지시사항등)**입니다. v0.2.1부터 보고서별 선택값에 따라 ☑/☐를 출력하며, 예전 양식의 체크박스 상태는 재사용하지 않습니다.
