# 업무보고 작업실

Windows에서 기존 업무보고를 참고해 AI와 초안을 작성하고, 고정 양식의 HWPX로 저장하는 로컬 웹앱입니다.

**[Windows 설치파일 다운로드](https://github.com/secret5028/upmu-bogo/releases/latest/download/UpmuBogo-Setup-0.2.1-x64.exe)** · [릴리스 및 변경사항](https://github.com/secret5028/upmu-bogo/releases)

## 무엇을 하는 프로그램인가요?

기존 업무보고를 폴더에 모으면 내용을 추출해 검색 가능한 **코퍼스(참고 문서 모음)**를 만듭니다. 새 업무의 자료와 요청을 입력하면 선택한 AI가 유사 보고서의 구성·문체를 참고해 제목과 본문을 제안합니다. 내용을 대화로 수정한 뒤, 승인 양식의 기호·글꼴·공백을 유지한 HWPX로 저장합니다.

**기존 보고서 폴더 → 코퍼스 구축 → 새 자료·요청 입력 → AI 제목·본문 제안 → 수정·검토 → HWPX 저장**

보고자·보고일자는 입력란에서 바꿀 수 있습니다. 보고목적은 보고서별로 네 항목 중 하나를 선택하며, 미선택이면 모두 빈 체크로 출력됩니다. 기존 보고서는 목적을 선택한 뒤 초안을 다시 생성해야 반영됩니다. 본문은 대화로 작성하고 오른쪽에서 확인합니다. 완성본을 참고사례로 저장하거나 작성 기준을 적용하면 다음 작성에 활용됩니다. AI 모델 자체를 학습시키는 기능은 아닙니다.

## 업무보고 샘플부터 보기

실제 사용했던 보고서의 **구성을 바탕으로 내용을 일반화한 공개용 예시**입니다. 실제 이름·연락처·기관 정보 및 내부 원문은 포함하지 않습니다. 날짜·참석 인원·조치내용은 예시이며 실제 업무의 근거나 사실로 사용하지 마세요.

| 예시 | 한글 문서 | 바로 읽기 |
| --- | --- | --- |
| 회의 참석 보고: 회의개요 → 회의결과 → 조치계획 | [HWPX](examples/01_회의참석보고.hwpx) | [본문](examples/01_회의참석보고.txt) · [양식 미리보기](examples/01_회의참석보고.svg) |
| 현장조사 결과 보고: 조사개요 → 조사결과 → 조치계획 | [HWPX](examples/02_현장조사결과보고.hwpx) | [본문](examples/02_현장조사결과보고.txt) · [양식 미리보기](examples/02_현장조사결과보고.svg) |

GitHub의 HWPX 파일 화면에서 **Download raw file**을 눌러 다운로드하세요. 샘플은 저장소에서 별도로 받으며, 현재 EXE에 자동 포함되지는 않습니다. [샘플 활용 안내](examples/README.md)를 참고하세요.

### 샘플로 첫 보고서 만들기

1. 아래 설치 방법대로 앱을 설치하고 **양식 수정**에서 보고자를 입력합니다.
2. 샘플 HWPX 2개를 PC의 한 폴더에 모읍니다. **참조 폴더·코퍼스**에서 그 폴더를 추가하고 **코퍼스 구축·갱신**을 실행합니다.
3. **AI 연결**에서 사용할 연결 방식을 설정합니다. AI가 준비되지 않았다면 아래 웹 채팅 복사·붙여넣기 방식도 사용할 수 있습니다.
4. **새 보고서**를 누르고 보고일자를 지정합니다. 관련 자료를 끌어 놓거나 파일 찾아보기로 추가합니다.
5. 대화창에 아래처럼 입력합니다. 실제 보고서를 만들 때는 자신의 업무 사실로 바꾸세요.

   > 회의 참석 보고를 작성해줘. 다음은 연습용 가상 내용이야. 2026년 11월 13일 14시부터 15시까지 가상시청 회의실에서 관계기관 담당자 6명이 겨울철 안전점검 준비회의에 참석했어. 기관별 담당 구역을 정했고 11월 20일까지 점검 일정을 제출하기로 했어. 기존 보고서의 구성과 문체를 참고하고 제목도 제안해줘. 알려주지 않은 사실은 만들지 말고 확인해줘.

6. AI가 제안한 초안을 적용하고, 수정할 부분을 대화창에 요청합니다. **양식 초안 생성** 후 미리보기에서 확인하고 검토 체크 → **완성본 저장**을 누릅니다.
7. **저장위치 폴더 열기**로 HWPX를 확인합니다. 다음 작성에서도 참고하려면 **이 완성본을 다음 보고서의 참고사례로 저장**을 선택합니다.

## 다운로드 및 설치

1. 위 **Windows 설치파일 다운로드**를 눌러 EXE 하나를 받습니다.
2. `UpmuBogo-Setup-0.2.1-x64.exe`를 실행하고 설치를 진행합니다.
3. 바탕화면의 **업무보고 작업실** 아이콘을 실행합니다.
4. **양식 수정**에서 보고자 정보를 입력하고 원하는 AI를 연결합니다.

**Python과 Node.js를 따로 설치할 필요가 없습니다.** 필요한 런타임과 문서 처리 라이브러리가 포함되어 설치 중 추가 다운로드도 없습니다. Windows 10/11 64비트용이며 관리자 권한 없이 현재 사용자에게 설치합니다. 크롬이 있으면 크롬으로, 없으면 기본 브라우저로 열립니다. AI 계정/API 연결은 별도로 설정합니다. 이 배포 EXE에는 공인 코드서명이 적용되지 않았습니다.

기본 프로그램 위치: `%LOCALAPPDATA%\Programs\UpmuBogo`  
보고서·설정 위치: `%LOCALAPPDATA%\UpmuBogo\data`

프로그램 제거 시 보고서와 설정은 별도 데이터 폴더에 남습니다. 이전 바탕화면 프로젝트의 자료는 자동 이전하지 않으며 참조 폴더에서 지정할 수 있습니다. 8765~8784 중 사용 가능한 로컬 포트를 사용합니다. 브라우저를 닫아도 백그라운드 서버는 유지되며 Windows 재시작 시 종료됩니다.

### 소스 코드로 설치하는 경우

개발자가 Code → Download ZIP으로 소스를 받은 경우에는 Python 3.11 이상과 Node.js 20 이상을 설치한 뒤 `install.cmd`를 실행합니다. 일반 사용자는 위 EXE 설치파일을 사용하세요.

## 사용 순서

1. **참조 폴더·코퍼스**에서 기존 결과물 폴더를 추가합니다. 새 폴더를 만들거나 바로 열 수 있습니다.
2. **코퍼스 구축·갱신**을 누릅니다. 하위 폴더까지 파싱하고 중복을 묶습니다. 다음 갱신은 변경된 파일만 다시 처리합니다.
3. 필요하면 **AI 작성 기준 분석**을 실행합니다. 전체 문서의 구조와 문체 표본을 분석하며, 제안된 기준은 검토 후 적용합니다.
4. 보고일자와 관련 자료를 입력하고 AI 대화창에서 보고할 사실을 설명합니다. AI는 코퍼스의 유사 사례와 저장한 작성 기준을 참고합니다. 사용한 사례 제목이 화면에 표시됩니다.
5. 제안된 제목·본문을 확인하고 **이 초안 적용 → 양식 초안 생성**을 누릅니다.
6. 미리보기와 내용을 검토한 후 **완성본 저장**을 누릅니다. 옆의 버튼으로 저장 폴더를 열 수 있습니다.

현재 사실은 새 입력·첨부자료에서 가져오고, 과거 보고서는 구성과 문체를 참고하도록 구분합니다. 모델을 재학습하는 방식은 아닙니다. 검색은 로컬 키워드와 문서 구조 점수 기반이며 임베딩 검색은 포함하지 않습니다.

## AI 연결

- 설치하고 로그인한 Codex CLI 또는 Claude Code CLI를 사용할 수 있습니다. CLI 인증은 해당 도구에서 직접 진행합니다. CLI 버전에 따라 지원 옵션 차이가 있을 수 있습니다.
- **AI 연결**에서 OpenAI, Anthropic 또는 OpenAI 호환 로컬 서버의 주소·모델·키를 설정할 수 있습니다.
- 웹 채팅에 프롬프트를 복사하고 JSON 응답을 가져오는 방식도 지원합니다.

| 연결 방식 | 준비할 것 | 사용 방법 |
| --- | --- | --- |
| GPT · Codex / Claude Code | 해당 CLI 별도 설치 및 계정 로그인 | 앱에서 공급자를 선택하고 대화 전송. CLI는 설치 EXE에 포함하지 않습니다. |
| API | 서비스 API 키·모델, 또는 실행 중인 호환 로컬 서버 | **AI 연결**에 주소·모델·키를 설정한 후 API 모드 선택 |
| ChatGPT / Claude 웹 채팅 | 해당 웹 서비스 이용 계정 | **웹 채팅으로 사용하기**를 펼쳐 프롬프트를 복사 → 웹 채팅에 붙여넣기 → 받은 JSON을 앱으로 가져오기. 자동 연결은 아닙니다. |

- AI 연결·계정·구독·API 키는 포함되지 않습니다. CLI 구독 또는 API 서비스의 사용 조건과 한도가 적용됩니다.
- 보고서 작성 요청과 검색된 사례의 발췌문은 선택한 AI에 전달됩니다. AI 패턴 분석은 모든 문서의 소제목·서식·문체 표본을 전달합니다. API 키는 Windows 사용자 계정으로 암호화해 로컬에 저장합니다.

## 데이터와 양식

- EXE 설치본의 개인 데이터는 `%LOCALAPPDATA%\UpmuBogo\data` 아래에 생성됩니다. 소스 설치본에서는 설치 폴더의 `data/`를 사용하며 Git에서 제외됩니다.
- 완성본: `data/70_완성문서`
- 기존 보고서 기본 폴더: `data/자료/기존 업무보고`
- 실제 파싱 결과, 코퍼스, 설정, 대화: `data/99_시스템`
- 실제 이름·연락처·기존 업무보고·API 키·로그는 배포 파일에 포함하지 않습니다. 기본 양식의 보고자 입력값은 비어 있습니다.
- 기본 HWPX는 `assets/approved.hwpx`입니다. 기호별 글꼴과 문단 간격을 보존해 생성합니다. 임의 양식 교체 UI는 아직 없으며 레이아웃 변경은 엔진의 입력란 정의와 함께 검토해야 합니다.
- HWP/HWPX/DOCX/PDF/TXT/MD 코퍼스를 지원합니다. HWP는 kordoc으로 읽습니다. HWPX에서 글꼴·간격도 추출합니다. 스캔 PDF/OCR과 일반 이미지의 내용 인식은 이 앱에 포함하지 않습니다.
- 미리보기는 kordoc 렌더링입니다. 실제 한글의 글꼴 설치 상태에 따라 모양·줄바꿈이 달라질 수 있으므로 최종 문서는 한글에서도 확인하세요. 글꼴 파일은 배포하지 않습니다.

업데이트 전 `data/`를 백업하세요. 설치를 다시 실행해도 개인 설정과 문서는 덮어쓰지 않습니다. 소스 설치본의 설치 경로를 옮기면 실행환경의 경로를 갱신하기 위해 재설치가 필요합니다. 기존 작성세션은 절대 경로를 포함하므로 그대로 이동 가능한 형식은 아닙니다.

## 백업 및 다른 PC에서 사용

`Win + R`에서 `%LOCALAPPDATA%\UpmuBogo`를 열어 **data 폴더 전체**를 별도 저장장치에 복사하면 문서·설정·코퍼스·작성 이력을 백업할 수 있습니다. 외부 경로로 지정한 참조 폴더와 저장 폴더는 별도로 복사해야 합니다. 개인 데이터나 백업은 이 공개 GitHub 저장소에 올리지 마세요.

다른 PC에는 EXE를 새로 설치하고, 기존 HWPX 자료를 복사한 뒤 앱의 **참조 폴더·코퍼스**에서 새 위치를 지정해 코퍼스를 구축하는 방법이 가장 간단합니다. 보고자와 저장 위치를 설정하고 AI 계정은 새 PC에서 로그인하세요.

**현재 버전에는 백업 가져오기나 경로 자동 이전 기능이 없습니다.** `data` 전체를 덮어쓰는 것만으로 완전한 이전이 되지 않습니다. 설정·코퍼스·작성 이력에 기존 PC의 절대경로가 들어 있어 경로 수정이 필요하며, Windows 계정으로 암호화한 API 키는 새 PC에서 다시 입력해야 합니다. 동일 PC 복구라도 실행 중인 서버를 종료한 상태에서 복원하세요. 브라우저를 닫는 것만으로 서버가 종료되지는 않습니다.

## 자주 묻는 질문

- **참고자료를 넣었는데 반영되지 않아요.** 파일 업로드는 이번 보고서의 관련 자료입니다. 과거 결과물은 참조 폴더에 모으고 코퍼스 구축·갱신을 실행하세요. 처리 결과에서 실패한 파일도 확인하세요.
- **자료 전체가 AI에 학습되나요?** 아닙니다. 로컬에서 검색하고 선택된 사례와 작성 기준을 요청에 함께 보냅니다. AI 분석을 실행하면 문서 구조·문체 표본이 해당 AI로 전달됩니다.
- **한글에서 모양이 달라요.** PC별 글꼴 설치 여부와 렌더러 차이가 영향을 줍니다. 폰트 파일은 포함하지 않으므로 최종 HWPX를 사용하는 한글 환경에서도 확인하세요.
- **설치만 하면 AI도 바로 되나요?** 문서 엔진은 포함되지만 AI 계정·CLI·API 서비스는 별도 준비가 필요합니다. 인터넷 없이 사용할 AI가 필요하다면 호환 로컬 서버를 직접 준비해야 합니다.

## 개발 및 검증

```powershell
.venv\Scripts\python.exe tests\test_corpus.py
.venv\Scripts\python.exe tests\test_distribution.py
```

`app/`는 웹앱, `engine/report_loop.py`는 보고서 생성 엔진입니다. `setup.py`가 실행 파일을 `data/99_시스템`에 배치합니다. 변경 후 설치를 다시 실행하고 실행 중인 서버는 재시작하세요. `tests/test_distribution.py`는 설치된 의존성을 사용해 임시 프로젝트에서 HWPX 생성과 검증을 수행합니다.

## EXE 빌드

`installer/build.py`는 공식 Python 임베디드 패키지와 Node.js ZIP, 고정된 Python 의존성 및 node_modules를 묶고 Inno Setup으로 EXE를 만듭니다. 빌드 전에 `install.cmd`로 소스 의존성을 설치하세요. Inno Setup 7 컴파일러가 필요합니다.

```powershell
python installer/build.py --downloads build-downloads --iscc "C:\Tools\Inno Setup 7\ISCC.exe"
```

빌드 산출물·실제 사용자 데이터는 소스 저장소에 올리지 않습니다. Python 및 Node 런타임 라이선스는 설치 폴더의 `runtime`에 포함됩니다.
