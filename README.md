# 업무보고 작업실

Windows에서 기존 업무보고를 참고해 AI와 초안을 작성하고, 고정 양식의 HWPX로 저장하는 로컬 웹앱입니다.

**[설치용 ZIP 다운로드](https://github.com/secret5028/upmu-bogo/releases/latest/download/work-report-workspace-0.1.0.zip)** · [릴리스 및 변경사항](https://github.com/secret5028/upmu-bogo/releases)

## 다운로드 및 설치

1. 위 **설치용 ZIP 다운로드** 또는 GitHub의 **Code → Download ZIP**으로 내려받아 압축을 해제합니다.
2. [Python 3.11 이상](https://www.python.org/downloads/windows/)과 [Node.js 20 이상](https://nodejs.org/)을 설치합니다. Python 설치 시 PATH 등록을 선택하세요.
3. 압축을 푼 폴더의 **install.cmd**를 더블클릭합니다. 최초 설치에는 인터넷이 필요하며 Python 패키지와 kordoc을 내려받습니다.
4. 설치 후 바탕화면의 **업무보고 작업실** 아이콘을 실행합니다. 크롬이 있으면 크롬으로, 없으면 기본 브라우저로 열립니다.
5. **양식 수정**에서 직책·이름·연락처를 입력하고 AI를 연결합니다.

현재 배포본은 설치 스크립트가 포함된 소스 배포본이며, Python/Node.js가 포함된 단일 EXE가 아닙니다. 설치 폴더는 쓰기 가능한 개인 폴더를 사용하세요. 다른 설치본이 8765 포트를 사용하면 중복 실행하지 않고 안내합니다. Windows 전체 기본 브라우저 설정은 바꾸지 않습니다.

## 사용 순서

1. **참조 폴더·코퍼스**에서 기존 결과물 폴더를 추가합니다. 새 폴더를 만들거나 바로 열 수 있습니다.
2. **코퍼스 구축·갱신**을 누릅니다. 하위 폴더까지 파싱하고 중복을 묶습니다. 다음 갱신은 변경된 파일만 다시 처리합니다.
3. 필요하면 **AI 작성 기준 분석**을 실행합니다. 전체 문서의 구조와 문체 표본을 분석하며, 제안된 기준은 검토 후 적용합니다.
4. 보고일자와 관련 자료를 입력하고 AI 대화창에서 보고할 사실을 설명합니다. AI는 코퍼스의 유사 사례와 저장한 작성 기준을 참고합니다. 사용한 사례 제목이 화면에 표시됩니다.
5. 제안된 제목·본문을 확인하고 **이 초안 적용 → 양식 초안 생성**을 누릅니다.
6. 미리보기와 내용을 검토한 후 **완성본 저장**을 누릅니다. 옆의 버튼으로 저장 폴더를 열 수 있습니다.

현재 사실은 새 입력·첨부자료에서 가져오고, 과거 보고서는 구성과 문체를 참고하도록 구분합니다. 모델을 재학습하는 방식은 아닙니다. 검색은 로컬 키워드와 문서 구조 점수 기반이며 임베딩 검색은 포함하지 않습니다.

## AI 연결

- 설치하고 로그인한 Codex CLI 또는 Claude Code CLI를 사용할 수 있습니다. CLI 인증은 해당 도구에서 직접 진행합니다. CLI 버전에 따라 지원 옵션 차이가 있을 수 있습니다.
- **AI 연결**에서 OpenAI, Anthropic 또는 OpenAI 호환 로컬 서버의 주소·모델·키를 설정할 수 있습니다.
- 웹 채팅에 프롬프트를 복사하고 JSON 응답을 가져오는 방식도 지원합니다.
- AI 연결·계정·구독·API 키는 포함되지 않습니다. CLI 구독 또는 API 서비스의 사용 조건과 한도가 적용됩니다.
- 보고서 작성 요청과 검색된 사례의 발췌문은 선택한 AI에 전달됩니다. AI 패턴 분석은 모든 문서의 소제목·서식·문체 표본을 전달합니다. API 키는 Windows 사용자 계정으로 암호화해 로컬에 저장합니다.

## 데이터와 양식

- 모든 개인 데이터는 `data/` 아래에 생성되며 Git에서 제외됩니다.
- 완성본: `data/70_완성문서`
- 기존 보고서 기본 폴더: `data/자료/기존 업무보고`
- 실제 파싱 결과, 코퍼스, 설정, 대화: `data/99_시스템`
- 실제 이름·연락처·기존 업무보고·API 키·로그는 배포 파일에 포함하지 않습니다. 기본 양식의 보고자 입력값은 비어 있습니다.
- 기본 HWPX는 `assets/approved.hwpx`입니다. 기호별 글꼴과 문단 간격을 보존해 생성합니다. 임의 양식 교체 UI는 아직 없으며 레이아웃 변경은 엔진의 입력란 정의와 함께 검토해야 합니다.
- HWP/HWPX/DOCX/PDF/TXT/MD 코퍼스를 지원합니다. HWP는 kordoc으로 읽습니다. HWPX에서 글꼴·간격도 추출합니다. 스캔 PDF/OCR과 일반 이미지의 내용 인식은 이 앱에 포함하지 않습니다.
- 미리보기는 kordoc 렌더링입니다. 실제 한글의 글꼴 설치 상태에 따라 모양·줄바꿈이 달라질 수 있으므로 최종 문서는 한글에서도 확인하세요. 글꼴 파일은 배포하지 않습니다.

업데이트 전 `data/`를 백업하세요. 설치를 다시 실행해도 개인 설정과 문서는 덮어쓰지 않습니다. 설치 경로를 옮기면 실행환경의 경로를 갱신하기 위해 재설치가 필요합니다. 기존 작성세션은 절대 경로를 포함하므로 그대로 이동 가능한 형식은 아닙니다.

## 개발 및 검증

```powershell
.venv\Scripts\python.exe tests\test_corpus.py
.venv\Scripts\python.exe tests\test_distribution.py
```

`app/`는 웹앱, `engine/report_loop.py`는 보고서 생성 엔진입니다. `setup.py`가 실행 파일을 `data/99_시스템`에 배치합니다. 변경 후 설치를 다시 실행하고 실행 중인 서버는 재시작하세요. `tests/test_distribution.py`는 설치된 의존성을 사용해 임시 프로젝트에서 HWPX 생성과 검증을 수행합니다.
