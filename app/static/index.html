    저장 폴더 설정

    완성본과 참조자료를 각각 원하는 폴더에 저장합니다. 기존 파일은 옮기지 않으며, 다음 저장부터 적용됩니다.

    원래 시스템의 작성세션·초안·완성본도 유지됩니다. 참조자료는 보고서별 하위 폴더에 보관됩니다.

    AI 연결 설정

    계정 로그인 방식은 Codex / Claude Code를 선택하세요. 아래는 API 또는 로컬 AI 서버 연결 설정입니다.

    키는 Windows 계정으로 암호화하여 이 PC에 저장합니다. 같은 주소에서 키를 비워두면 기존 키를 유지합니다. 외부 API는 해당 서비스의 사용료가 적용될 수 있습니다.

    보고자 양식 수정

    직책·이름(내선)·연락처·보고목적을 수정할 수 있습니다. 저장하면 모든 보고서의 다음 초안 생성부터 적용됩니다. 기존에 저장한 파일은 바뀌지 않습니다.

    작성 기준·참고사례

    모델 자체를 재학습하는 대신 저장한 기준과 확정본을 다음 작성 때 참고합니다. 이번 업무만의 인명·날짜·수치는 지속 기준에 넣지 마세요.

    확정한 참고사례

    체크를 해제하고 저장하면 다음 검색에서 제외합니다. 원본 문서는 삭제하지 않습니다.

    참조 폴더 · 보고서 코퍼스

    기존 결과물을 모아 둔 폴더를 지정하세요. 하위 폴더까지 읽고 중복을 묶어 AI가 참고할 사례로 구성합니다. 원본 파일은 변경하지 않습니다.

    새 폴더에 기존 업무보고를 넣고 코퍼스 구축·갱신을 누르세요. 경로가 비어 있으면 기본 폴더를 생성합니다.

    HWP · HWPX · DOCX · PDF · TXT · MD / 일반 갱신은 새 파일·변경 파일만 파싱합니다. 스캔 PDF 등 텍스트가 없는 파일은 실패 목록에 표시됩니다. 글꼴·간격 추출은 HWPX를 지원합니다.
